\begin{abstract}
Cloud-hosted large language models (LLMs) are increasingly used for root
cause analysis (RCA) in AIOps pipelines, but they introduce data privacy
risk, network latency, and per-query cost that scale poorly with production
log volumes. We present LogSentinel, a benchmark evaluating open-weight
LLMs served locally via vLLM on a single high-memory workstation GPU
(NVIDIA RTX PRO 6000, 96GB) against a cloud API baseline and a classical
LSTM-based log anomaly detector (DeepLog), across four real, publicly
available log datasets (BGL, HDFS, Thunderbird, OpenStack). We report
accuracy, precision/recall, and F1 with bootstrap 95\% confidence
intervals across 3 random seeds, alongside throughput and VRAM footprint
for models ranging from 8B to 70B (4-bit quantized) parameters. We further
ablate prompt style (zero-shot vs. few-shot) and batch size scaling on a
single GPU. Our results show [FILL IN YOUR TOP-LINE FINDING]. We release
our benchmark harness, dataset splits, and evaluation code to support
reproducible on-premise AIOps research.
\end{abstract}

\section{Experimental Setup}
\subsection{Hardware}
All local-model experiments were run on a single workstation equipped with
an NVIDIA RTX PRO 6000 (96GB VRAM), serving models via vLLM~\cite{vllm2023}.

\subsection{Statistical Methodology}
Each configuration (model $\times$ dataset $\times$ prompt style) was run
across 3 random data-sampling seeds. We report bootstrap 95\% confidence
intervals (1000 resamples) on F1 scores.
